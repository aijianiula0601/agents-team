# 管理页面

`adminweb` 通过 Go `embed` 将中文管理页面随中转站二进制部署，无需 Node.js 构建步骤，也不依赖外部 CDN。

## 接入

主 HTTP 路由注册 `mux.Handle(prefix+"/admin/", adminweb.Handler(prefix))`。页面默认地址为 `/agents-team/admin/`；API 位于同级 `./api/`，由 `management.Server.Register` 注册更具体的路由。已有 `httpapi.Server.WithManagement` 完成接入。

## 功能与口径

- 邮箱密码注册、登录与退出；服务端 HttpOnly Cookie 保存会话，CSRF token 只保存在页面内存中。
- 运行总览：注册账号、今日新增、近 7 天活跃账号、在线设备、主电脑在线率、任务总量及成功率、版本总量与下载请求。接口缺少的指标不展示。
- 趋势分析：原生 SVG 多系列折线图，“任务运行”和“账号与设备增长”两个维度，可点击图例隐藏曲线、指针或左右方向键查看单日值；右上角提供 7/30/90 天与原生日期日历，默认最近 30 天，最大 366 天，支持展开每日明细表。
- 账号与设备：服务端搜索与分页，设备连接状态、所属账号、主电脑及最近心跳；普通账号只能读取本人范围。
- 账号管理：仅服务端确认的 `superadmin` 展示编辑、重置密码和删除；`admin` 没有账号变更入口。受保护账号不允许操作，Google 账号不可改邮箱或重置密码。修改邮箱或重置密码会撤销全部浏览器及设备会话；删除必须手动输入完整邮箱，明确提醒同时删除关联设备、邀请码、聊天快照、任务和租约。
- 任务统计：待处理、执行中、成功及失败，状态筛选、搜索、分页；仅显示元数据，不显示聊天正文。
- 版本发布：macOS DMG、Android APK；版本、构建号、架构、说明、文件预检与真实上传进度；上传先存草稿，确认发布，支持撤回及已发布安装包下载。

“今日”和趋势按 UTC 自然日统计；日期范围只影响趋势，指标卡保留累计、今日、实时口径。列表时间显示北京时间。活跃账号指近 7 天有设备心跳的账号；在线指最近 60 秒有心跳；任务成功率为 `done / (done + failed)`；下载数包含 Range 续传请求，不代表安装数。没有最终任务结果或没有主电脑时，比率显示 `—`。

趋势请求为 `overview?startDate=YYYY-MM-DD&endDate=YYYY-MM-DD`，包含首尾两日。任务按创建日期分组，成功/失败反映任务当前状态，并非当天状态变更；新增设备包含之后被撤销的设备。历史曲线使用现存记录，账号硬删除后关联历史点会减少，不应视为审计记录；没有历史心跳明细，因此不显示历史在线量或活跃人数曲线。

管理员由服务端预置身份决定，普通注册不会获得发布权限。未配置共享安装包存储时，页面显示原因并禁用上传和下载。客户端平台标识采用 `mac`、`android`，成功任务状态采用 `done`。

## 安全与验证

动态数据统一通过 `textContent` 或 DOM API 渲染，不使用 `innerHTML`。安装包下载 URL 限制为同源 HTTP(S)。页面 CSP 仅允许同源资源，不加载外部脚本、字体、统计或图片。表单提前校验密码、说明、文件名 UTF-8 字节数；服务端仍必须执行全部校验与权限检查。

验证命令：`go test ./internal/adminweb`，以及对 `app.js`、`analytics.js`、`accounts.js` 执行 `node --check`。启动完整中转站服务后访问 `http://127.0.0.1:端口/agents-team/admin/`；本地 `RELAY_PUBLIC_URL` 须对应相同 HTTP 源，以保持 Origin 校验和 Cookie Secure 配置一致。验收覆盖注册登录、普通账号范围、超级管理员账号操作、保护账号、UTC 日期范围/曲线切换、管理员草稿发布/撤回、刷新后的真实数据、窄屏布局及安装包上传错误。
