# 静态资源

`app.css` 包含基础页面布局和组件，`analytics.css` 负责趋势分析与账号操作界面的响应式样式；`app.js` 负责会话、统计与分页、安装包发布；`analytics.js` 负责 UTC 日期范围、多系列原生 SVG 趋势与图例交互；`accounts.js` 负责仅超级管理员可用的账号编辑、重置密码和删除确认。所有资源随 Go 二进制嵌入，无外部 CDN 依赖。

脚本均使用 `defer`，业务模块先定义函数，最后由 `app.js` 初始化。账号操作以后端 `role=superadmin` 判定显示，普通管理员仍可看全局统计和发布版本。密码仅存在于输入框和当前请求，提交后或会话退出立即清空。删除需输入目标完整邮箱确认。

后端 API 以当前 `/admin/` 页面为基准使用 `./api/`。动态文本必须经 DOM API 写入，不允许使用 HTML 字符串拼接；Cookie 会话与 CSRF token 不存储到 localStorage。列表请求序号防止旧响应覆盖新筛选结果，会话版本防止旧请求的 401 响应清除新登录。
