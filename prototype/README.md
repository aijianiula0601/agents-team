# Chorus 桌面原型

Mac 风格多 Agent 群聊产品的可交互 HTML 原型。

## 打开方式

```bash
open prototype/index.html
```

或在浏览器中直接打开本目录下的 `index.html`。

## 可体验交互

- 切换群聊 / 选中 Agent 查看右侧详情
- **新建 Agent**（三步：人设 → 模型 → Harness）
- **新建群**（拉入多个 Agent、选发言规则）
- 发送消息，观看 Agent 接力回复
- 输入 `@` 点名；群设置为「仅 @」时需点名才回复
- 点群聊：右侧为群设置（改名、工作区、拉人、踢人）
- 点 Agent：右侧只显示 Agent 信息，并可编辑
- 左下角登录；小齿轮进入设置（外观随系统 / Dark / Light）

安装包在 `mac-app/` 与 `android-app/`，说明见仓库根目录 `README.md`。
