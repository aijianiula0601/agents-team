# shared/web

Chorus 双端共用的界面资源。

| 文件 | 说明 |
|------|------|
| `index.html` | 主界面与弹窗结构 |
| `app.js` | 团队、私聊、草稿、执行和设置交互 |
| `conversation.js` | 共享上下文、点名与配置校验 |
| `host-config.js` | 主电脑短期配置命令、身份隔离、模型密钥端到端加密 |
| `gateway-client.js` / `terminal-ui.js` | 手机到 Mac 的鉴权连接、xterm 原生交互终端 |
| `vendor/` | 随应用打包的 xterm 与 FitAddon，无需外网加载 |
| `model-client.js` | 浏览器与 Android 直连模型、超时和取消 |
| `app.css` / `workbench.css` | 基础样式与正式工作台、响应式布局 |
| `platform.css` / `platform.js` | 原生标题栏、平台能力、手机抽屉与返回键 |

同步到客户端：

编程 Agent 的文件空间默认自动管理，纯对话不创建目录；只有操作已有项目时才展开“绑定已有项目”。`workspaceMode=auto` 在当前主电脑重新解析目录，已有路径缺少模式时按显式项目保留。所有已同步账号设备可新建、编辑、删除 Agent 与团队；项目路径指向主电脑并通过配置通道校验，目录选择器仅在主电脑显示。

```bash
node ../../scripts/sync-ui.js
```

邮箱登录与注册使用同一中转认证接口：注册包含确认密码、本机校验和原地错误，确认密码不会上传。账号角色仅从认证响应读取；退出立即隔离旧请求、聊天、草稿、附件与终端，再等待服务器注销，断网时仍可本机退出。各账号的缓存独立保存，重新登录恢复自己的草稿及待同步记录。终端重置使旧 open、帧、输入与订阅失效，避免跨账号复用输出。

群聊采用按需参与：候选成员通过自己的模型或 CLI 结合职责、已有上下文和触发发言判断相关性，需要沉默时返回内部标记 `[[CHORUS_SILENT]]`，界面不保存该标记，也不发送完成通知。正常回复中的准确 `@成员名` 会唤起对应群成员；每条用户消息内，每个成员最多观察两次，自动追加观察最多八次，避免循环。回复保留 `replyTo` 触发来源，断线续接时跳过已完成的点名。私聊和单条失败重试保持独立，不自动扩散到其他成员。

群聊运行时显示正在执行的成员，生成正文后逐段展示，手机收到旧主电脑的「正在查看群聊…」状态时也使用此文案。工作区保存 Agent 实际创建的代码、文档等文件；聊天记录由客户端本地缓存和已登录的中转站单独保存，CLI 原生会话由对应后台管理。仅聊天不会自动生成工作区文件，Agent 详情中的文件空间说明会提示这一点。

Agent/群 CRUD 与共享设置统一使用版本化 REST 接口和打开表单时的版本；仅聊天导致的版本变化自动重试一次，配置冲突不丢输入。新版本配置中的成员集合、群规则和共享设置为权威来源，删除项不会被主电脑旧快照恢复。快照中的 `configRevision` 防止主电脑旧配置覆盖远端保存；`harnessModels` 只由主电脑发现并发布，`harnessModel` 与直连模型字段 `model` 分离。通知统一使用应用总开关。设置内容与导航独立滚动，设备主机状态在界面与服务端同时校验。

聊天滚动由 `app.js` 的 `updateMessageViewport` 统一处理：后台刷新和新回复保留正在阅读的消息及其屏内偏移；只有原本贴底、切换会话或主动发送时显示最新消息。同内容刷新不替换消息 DOM，重试和补齐历史使用消息 ID 恢复位置；滚动同步完成，避免延迟动画覆盖手动操作。运行提示和输入框高度变化也保留原来的贴底状态。

## 在线更新

`updates.js` 负责公开清单检查、平台/版本适配和异步状态隔离；`update-ui.js` 绑定侧栏、手机入口和设置页；`updates.css` 仅负责更新区域样式。安装版本来自 Electron 或 Capacitor 原生桥接，安装包下载、哈希验证和系统安装在原生层完成。切换中转站时清除旧清单，下载中阻止切换地址。无更新接口的旧中转站在设置页明确提示，不影响聊天。

## 并行与流式执行

`dispatchAgentReplies` 按波次冻结已完成上下文，最多 8 个成员并发执行，更多成员排队；独立 `runId` 隔离进度和取消；共享工作区任务在波次内排队。收到完整回复后处理 @ 交接，未完成分片不进入模型上下文或已完成判定。`streaming` 标记在消息规范化和中转合并中保留，包括显式 `false`，避免旧分片覆盖最终状态。

累计正文按稳定消息 ID 更新，DOM 与本地保存分别限频，保留既有阅读位置。中转上传先冻结快照，防止发送期间产生的新分片被误记为已发布；远端任务完成前等待最终快照确认。模型原生流和桌面进度不会在账号切换、停止或完成后继续写入旧任务。
